netcfg-vault

一条命令，备份整个机房的设备配置

GitHub 获取

30 秒上手

pip install git+https://github.com/BG8CFB/netcfg-vault.git
export NETCFG_PASSWORD='你的密码'
netcfg-vault backup devices.yml --out backups

核心能力

批量备份

H3C / 华为 / 思科 / 锐捷，SSH 批量拉取 running-config，按日期归档。

智能 diff

自动过滤时间戳等噪声行，只看真实配置变更，附 +N/-N 统计。

定时备份

watch 模式周期执行，失败设备即时上报。

Webhook 告警

钉钉 / 企业微信 / 飞书 / Server酱，一个环境变量配置。
