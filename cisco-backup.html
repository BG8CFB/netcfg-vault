思科交换机配置备份: 3 种方法对比 + 自动化方案

思科 IOS 交换机的配置备份是日常运维的高频操作。本文覆盖手工导出、TFTP/FTP 传输、脚本自动批量备份三种方式, 并给出定时备份 + 加密归档的完整方案。

方法一: 手工备份 (show 命令导出)

登录交换机后执行:

CS-SW# show running-config
CS-SW# show startup-config

running-config 是当前运行配置, startup-config 是已保存配置。两者不一致说明改过没 copy run start。终端里直接全选复制到本地文件。

缺点: 设备一多就不可维护, 无法追溯每天改了什么。

方法二: TFTP/FTP 备份

CS-SW# copy running-config tftp://192.168.1.100/cs-sw1-confg

适合单台应急, 但需要内网有 TFTP/FTP 服务, 且 TFTP 明文传输。

方法三: Python 脚本自动批量备份 (推荐)

pip install netcfg-vault
netcfg-vault init
export NETCFG_PASSWORD='设备密码'
netcfg-vault backup devices.yml --out backups/

一条命令批量备份全网思科/H3C/华为/锐捷设备, 按日期归档, 自动过滤 diff 噪声, 支持 AES-256-GCM 加密保险库和钉钉/企微告警。免费版支持 5 台。

定时备份 (Linux)

netcfg-vault init   # 生成 systemd service + timer, 每天 02:30 自动备份
systemctl enable --now netcfg-backup.timer

常见问题

备份的文件在哪? 默认 backups/日期/设备名.cfg。

如何看今天改了什么? netcfg-vault diff backups/昨天/ backups/今天/

配置文件能加密吗? netcfg-vault vault save backups/ --out configs.nvault --ask-pass
