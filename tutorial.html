H3C / 华为 / 思科交换机配置自动备份教程

netcfg-vault 是一个开源 CLI, 专为网络工程师设计: 批量备份多厂商设备配置、diff 变更、AES-256-GCM 加密存储、定时任务、Webhook 告警。本文从零开始, 5 分钟跑通。

1. 一键初始化 (v0.8.0 新增)

netcfg-vault init

自动生成 devices.yml 清单模板、systemd 定时服务、cron 示例, 30 秒搭好整套自动备份。

2. 安装

pip install netcfg-vault

支持 Python 3.8+, 依赖 paramiko + cryptography, Windows/Linux/macOS 通用。

3. 写设备清单

devices:
  - name: core-sw1
    host: 192.168.1.1
    vendor: h3c          # h3c / huawei / cisco / ruijie
    protocol: ssh
    username: admin
  - name: acc-sw2
    host: 192.168.1.2
    vendor: huawei
    protocol: ssh
    username: admin

4. 一次备份全部设备

export NETCFG_PASSWORD='你的设备密码'
netcfg-vault backup devices.yml --out backups/

输出按日期归档: backups/2026-11-10/core-sw1.cfg。免费版支持 5 台设备, Pro 授权无限台。

5. 看今天改了什么 (diff)

netcfg-vault diff backups/2026-11-09/ backups/2026-11-10/

自动过滤时间戳/uptime 噪声, 只留真实配置变更。

6. 加密保险库 (防泄漏)

netcfg-vault vault save backups/ --out configs.nvault --ask-pass
netcfg-vault vault list configs.nvault --ask-pass

AES-256-GCM + PBKDF2 600k 迭代, 配置文件落盘即密文, 丢 U 盘/传网盘都安全。

7. 安全巡检与报告 (v0.6+)

netcfg-vault audit backups/2026-11-10/ --out audit.csv
netcfg-vault report backups/2026-11-10/ --out report.html

audit 扫描 telnet 开启/SNMP 默认社区/弱口令等 6 类隐患输出 CSV; report 一条命令生成带日间对比的 HTML 巡检报告。

8. 定时备份 + 钉钉/企微告警

export NETCFG_WEBHOOK='https://oapi.dingtalk.com/robot/send?access_token=xxx'
netcfg-vault watch devices.yml --interval 86400

每天自动备份, 失败设备自动推送到钉钉/企业微信/飞书/Server酱。

为什么需要自动备份?

设备更换、误删配置、审计要求、故障回滚 — 配置备份是网络运维的第一道保险。手工 display current-configuration 复制粘贴无法规模化, 也无法追溯变更。
